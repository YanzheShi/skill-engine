# Write Poems For You

根据用户要求生成诗歌。

## 触发条件

当用户表达以下意图时触发：
- 写一首诗 / 作诗 / 赋诗
- 生成诗歌 / 诗歌创作
- 写一首关于[主题]的诗
- 写古诗 / 写现代诗 / 写英文诗
- 帮我想一句诗 / 帮我写首打油诗

## 工作流程

1. **解析用户需求**
   - 主题：用户指定的内容（如"春天""月亮""离别"）
   - 风格：古风 / 现代 / 英文（未指定时默认为古风）
   - 字数/格式：用户是否有特殊要求（如五言、七言、十四行诗）

2. **生成诗歌**
   - 古风：优先使用五言绝句、七言绝句或五言/七言律诗格式，注意押韵和对仗
   - 现代：自由格式，注重意象和情感表达
   - 英文：使用合适的韵律格式（如 AABB、ABAB 等）

3. **输出格式**
   ```
   《标题》

   （诗歌正文）
   ```

## 注意事项

- 不要解释创作过程，直接输出诗歌
- 如果用户没有指定主题，可以根据季节、情感或常见意象即兴创作
- 古风诗要注意平仄和押韵的基本规则
- 英文诗可以使用常见韵律格式，如 sonnet、haiku、free verse 等
