## 🚀 快速开始

### 准备工作

1. **准备简历**：把你的简历（PDF或DOCX格式）放到 `input/` 文件夹里
2. **运行脚本**：

```bash
cd interview-simulator
python scripts/interview_simulator.py
```

## 🎭 面试官人设大揭秘

### 🌟 简单级 - 友好鼓励型
> "别紧张，慢慢来，我相信你可以的！"

适合初次面试者或想要建立信心的同学。语气温和，积极反馈，像一位温柔的学长。

### 🤝 中等级 - 专业标准型
> "感谢您的回答，能否再详细说明一下？"

最接近真实面试场景，客观公正，注重细节，像一位资深HR。

### 😎 困难级 - 严谨专业型
> "这个项目中你遇到的最大挑战是什么？具体是如何解决的？"

深入挖掘你的经历，注重逻辑和细节验证，像一位技术总监。

### 🔥 地狱级 - 压力挑战型
> "我注意到你在上一家公司只待了半年，这是为什么？"

模拟高压面试环境，犀利追问，挑战你的心理极限，像一位严厉的CEO。

## 📊 评分维度

面试结束后，我会从以下五个维度给你打分：

| 维度 | 权重 | 评估要点 |
|------|------|---------|
| 📝 简历真实性 | 20% | 回答与简历是否一致 |
| 🗣️ 沟通表达 | 20% | 逻辑清晰，表达流畅 |
| 💼 专业能力 | 25% | 对工作的深入理解 |
| 🎯 职业素养 | 15% | 职业规划清晰 |
| ⚡ 临场反应 | 20% | 应变能力，抗压能力 |

## 💡 面试小贴士

1. **提前准备**：把简历内容烂熟于心，准备几个经典案例
2. **STAR法则**：情境(Situation)→任务(Task)→行动(Action)→结果(Result)
3. **保持微笑**：即使紧张也要保持自信的表情
4. **反问面试官**：面试是双向选择，也要考察公司是否适合你
5. **练习！练习！练习！**：熟能生巧，多练几次自然就不紧张了
