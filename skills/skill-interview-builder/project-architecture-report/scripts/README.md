# scripts/ 目录

## 用途
存放辅助脚本，用于在项目分析过程中自动提取代码结构信息。

## 当前文件
| 文件名 | 说明 | 状态 |
|--------|------|------|
| `code_analyzer.py` | 提取项目模块/函数调用关系和代码依赖层级的辅助脚本 | ⚠️ 待补充 |

## 待补充内容
`code_analyzer.py` 当前为框架代码，需要用户根据目标项目的语言和结构完善以下功能：

1. **文件解析逻辑**：为项目的具体语言（Python/JavaScript/TypeScript/Java/Go 等）完善解析器
2. **依赖关系构建**：完善模块间依赖关系的分析逻辑
3. **调用链提取**：实现函数调用关系的精确提取

### 使用方式
```bash
# 将脚本复制到项目根目录后执行
python code_analyzer.py
```

### 输出
脚本会生成 `project_structure.json` 文件，包含模块、函数、依赖关系的结构化数据，供主 Skill 的 Step 2 使用。
