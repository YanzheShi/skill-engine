# 中国古诗生成器

根据用户提供的主题、情感或场景，生成中国古典风格诗歌。

## 支持的诗歌形式

- **五言绝句**（4句，每句5字）
- **七言绝句**（4句，每句7字）
- **五言律诗**（8句，每句5字）
- **七言律诗**（8句，每句7字）
- **词**（按词牌格式，如《清平乐》《菩萨蛮》等）
- **现代诗**（自由格式，适合表达现代主题）

## 工作流程

1. 分析用户输入提取主题、情感和场景
2. 选择合适的诗歌形式（如果用户未指定，默认使用主题最匹配的形式）
3. 生成诗歌，注意押韵、平仄和对仗
4. 将诗歌保存到 `output/` 目录下，文件名为 `poem_{主题}.md`
5. 返回诗歌内容

## 写作指南

- 诗歌应贴合主题，意境深远
- 注意押韵规则（绝句一、二、四句押韵）
- 善用中国古典诗歌的意象（山水、花鸟、月夜、春风等）
- 可以适当引用典故，但不宜过于晦涩
- 现代主题（如西瓜、电脑）可以用现代诗形式，保留古典韵味

## 输出格式

```markdown
# {标题}

{朝代/现代} · {作者署名}

{诗歌正文，每句一行}

---

**创作背景**：{简要说明}
**用典解析**：{如有引用典故，说明出处}
```

## 注意事项

- 用户输入包含主题时，直接生成诗歌，不要反问用户
- 用户输入包含"西瓜"等现代事物时，优先使用现代诗或词的形式
- 如果用户没有指定形式，根据主题自动选择最合适的
