# 📋 Learning Log — 面试卡片

> **使用说明**：每轮学习会话结束后，由 Orchestrator 自动填充此模板，
> 生成一份可复用的面试备战卡片。**Tags 字段用于跨模块检索**。
>
> 💡 建议归档路径：`learning-logs/<模块名>-<日期>.md`

---

## 基本信息

| 字段 | 内容 |
|---|---|
| 模块名称 | `<ModuleName>` |
| 文件路径 | `<path/to/file>` |
| 学习日期 | `<YYYY-MM-DD>` |
| 会话轮次 | `<#N>` |
| 参与角色 | 📖 讲解者 / 🔍 质疑者 / 🏛️ 评审员 / 🧪 测试 / 🔧 SRE / 🛡️ 安全 |
| 项目/仓库 | `<project-name>` |
| 技术栈标签 | `<go, redis, mysql, kafka, ...>` |

## 🏷️ Tags（知识点标签）

> **重要**：填写以下标签，用于后续 `extract-cards.py` 自动汇总检索。

```yaml
tags:
  # 架构层面
  architecture: [微服务, 单体, 事件驱动, CQRS, DDD, 分层架构]
  # 设计模式
  patterns: [工厂, 策略, 装饰器, 观察者, 单例, 模板方法, 代理]
  # 并发与分布式
  concurrency: [goroutine, channel, mutex, 分布式锁, 共识算法, 幂等]
  distributed: [CAP, 一致性, 分区容忍, 脑裂, 数据分片, 主从复制]
  # 数据层
  data: [索引, 事务隔离级别, 乐观锁, 悲观锁, 连接池, 缓存穿透]
  # 中间件
  middleware: [Redis, Kafka, RabbitMQ, Nginx, Envoy, gRPC]
  # 安全
  security: [SQL注入, XSS, CSRF, 越权, 加密, 认证, 鉴权]
  # 测试
  testing: [单元测试, 集成测试, 混沌工程, 边界用例, Mock]
  # 运维
  sre: [监控, 告警, 熔断, 限流, 降级, 链路追踪, 优雅关停]
  # 面试维度
  interview_topics: [系统设计, 算法, 代码细节, 权衡决策, 故障排查]
  # 自定义
  custom: []
```

> 💡 只保留适用的标签，删除不适用的。标签越精准，检索越高效。
